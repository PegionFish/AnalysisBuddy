# 契约变更提案模板（contract-change-proposal）

> 用途：判为 **Schema/契约缺陷** 的勘误条目（见 `schema-errata.md`）提变更提案。
> 流程：本模板成文 → 提交**主代理审批** → 获批后**全路广播**（受影响路同步修订）
> → docs/spec 与 protocol-v1.md 同批落地 → validator 规则 / ab-protocol 类型 /
> 开发者指南四处同批同步（E-03 DoD：无单点漂移）。
> 未获批前，docs/spec 与 protocol-v1.md **零改动**（PLAN.md §6 规则 1）。

## 模板使用说明

- 每份提案对应一个勘误条目；根因相同可合并（如 E-01/E-02 共用提案 A）；
- 获批后：修订落地 → 重跑 `cargo test schema_feedback`（复现矩阵全绿）→
  schema-errata.md 对应条目「处置」列更新为审批结论与落地 commit；
- 文档表述不一致类（文档缺陷）**不走本流程**，归 E-01 指南修订。
