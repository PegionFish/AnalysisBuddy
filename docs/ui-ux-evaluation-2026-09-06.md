## 2. 问题清单（本轮）

严重度：🔴 高 ｜ 🟠 中 ｜ 🟡 低。复现均基于 mock 模式。

### 🔴 2.1 卸载插件无确认、无撤销、无完成反馈（回归：08-12 报告 P1，至今未修）
- 现象：插件页点击 demo-tool「卸载」→ 列表**立即**移除（t15→t16，DOM 确认 `demo-tool` 消失、无任何对话框）。
- 影响：不可逆破坏性操作一键直达；多用户/在线服务版中风险放大（见 §4）。
- 建议：主题化确认 Dialog（显示插件名与删除范围说明）→ 成功 toast + 撤销窗口；操作期间 busy 禁点；焦点管理。

### 🔴 2.2 图表缩放重查后序列以极暗颜色渲染，与图例色不一致（新发现）
- 复现：导入勾选 4 序列（t07 鲜亮）→ dataZoom 拖拽缩放（t09b）→ 「重置缩放」（t10）→ metric_2（橙）/metric_4（紫）变为约 20% 不透明度的暗棕/暗蓝细线，图例色块仍鲜亮；点一次图例开/关后恢复鲜亮（t11→t12）。
- 附带：「已降采样」徽标在重置回全窗口后仍不消失。
- 影响：缩放是核心分析动作，重查后两条曲线近乎不可见，且颜色对不上图例，用户会误以为数据消失。
- 建议：排查 TimelineChart 重查路径的 setOption（疑似 series 重用/透明度状态残留，或降采样渲染分支），重置缩放时同步重算降采样徽标。

### 🟠 2.3 窄屏顶栏不换行，整页被撑到 787px（回归：08-12 P2 仅修了工作台一半）
- 几何实测（390×844）：`docScrollW=787`；根因 `.topbar`（会话路径输入 + 打开/保存/另存/新建/语言/主题一字排开）不换行不收缩；`.app-shell` 及插件页内容随之拉宽（t22/t23）。
- 工作台侧 <1000px 抽屉降级已生效（右栏→浮动"Key Values"抽屉，t24），但顶栏溢出使用户仍需横向滚动才能看到图表。
- 建议：顶栏改 flex-wrap 或溢出收进「更多」菜单；插件页断点降级（卡片单列已可用，需消除最小宽度约束）。

### 🟠 2.4 插件页内容列仅占 ~57% 宽（新发现）
- 1280px 下卡片与拖放区固定在左侧 ~735px，右侧大片空白（t15），与工作台的满幅密度不一致。
- 建议：列表区 `max-width` 提到 ~900–1000px 或让卡片 `stretch`，空白区可放汇总/统计。

### 🟡 2.5 左栏 3px 横向溢出 → 常驻横向滚动条（新发现）
- 1280px 空状态即可复现：`.app-shell__left` scrollWidth 282 / clientWidth 279（t02 底部滚动条全程可见）。
- 建议：检查 resize 手柄/内容 3px 超出（疑似把手柄定位在外侧），或 `overflow-x: hidden`。

### 🟡 2.6 窄屏关键值抽屉标题渲染两次（新发现）
- t24："KEY VALUES" 在抽屉头部与面板自带标题各出现一次。建议抽屉壳不传标题或面板标题在抽屉模式下去重。

### 🟡 2.7 游标 axisPointer 时间标签与图例文字重叠（新发现）
- t07/t11：设置游标后 `08:05:25.270` 标签盒压在图例行上。建议 axisPointer label 放入 x 轴末端或加背景留白。

### 🟡 2.8 拖拽导入区无键盘/读屏语义（回归：08-12 P2，至今未修）
- DOM 实测：`div[data-testid=dropzone]`——`role=null`、`aria-label=null`、`tabIndex=-1`、`cursor=default`。键盘与读屏用户只能靠旁边的路径输入框（要求知道完整路径）。
- 建议：区域内加「选择文件…」真按钮 + 区域 `role=button`/`tabindex=0`/Enter·Space 触发 + 说明支持格式。

### 🟡 2.9 控件尺寸普遍偏小（回归：08-12 P2，未修）
- 实测：导航按钮高 24px、导入/保存/主题按钮高 25px、字号一律 12px。低于桌面建议下限 32px。
- 建议：主要操作 ≥32px；正文字号 ≥12px 仅用于次要信息；连续小按钮组加间距或收进菜单。

### 🟡 2.10 dataZoom 两端标签格式不一致且右端截断（新发现）
- t09：缩放后左端 `08:00:00`（纯时间）、右端 `1970-01-01 08:10:0…`（带日期且省略截断）。统一走 `formatTime` 并测试边界。

### ⚠️ 2.11 观察：日志抽屉打开期间页面无法静默
- 两次打开抽屉后截图管线均 30s 超时（DOM 读取正常、无 CSS 动画、滚动静止），关闭/重开标签即恢复。疑似抽屉打开后有持续微变更（如定时器/观察器）。对用户意味着潜在常时 CPU/电耗，建议排查；亦可能纯属截图工具静默判定，需在桌面壳复测。

### 🟡 2.12 指标描述英文混排（回归：08-13 P10）
- 中文 UI 下显示 `synthetic metric 1 for mock-…`（插件 schema 原文）。建议宿主本地化映射或插件 description 双语。

### 2.13 环境限制（非缺陷）
- ZIP 安装（点选文件/拖放）在浏览器自动化下不可驱动（IAB 无文件选择器）；更新流（检查→确认→更新）因此未走通 GUI 验证，仅确认按钮渲染条件正确。
- 原生对话框、WebView2 无障碍树暴露为 real 模式范围，本轮未复测。

## 4. 在线服务版（ab-server + Web 前端）权限系统设计建议

背景：ab-server 已具备 Bearer token 认证（`--token`）与 19 命令等价端点；DTO 与桌面前端 ipc 契约同形。需求：**仅 sysadmin 可执行深度配置（插件包管理：安装/卸载/禁用/更新/重载）**，普通用户可分析数据。

### 4.1 角色与认证（服务端为唯一权威）
- 最小角色集：`viewer`（数据分析）/ `sysadmin`（深度配置）。启动参数改为 `--admin-token` + `--viewer-token`（或 token 文件 `tokens.json`：`{token → role}`），健康端点保持匿名。
- 新增 `GET /api/v1/whoami` → `{ role }`，前端启动时调用并存入 session state。
- **判定必须在服务端**：管理面端点对 viewer 一律 `403 { code: "permission_denied" }`；前端隐藏按钮只是体验优化，不是安全边界。

### 4.2 命令→权限矩阵（映射现有 19 命令）
- viewer：`import_files` / `unload_file`（仅本人导入的文件）/ `get_metrics` / `query_series` / `key_values_at` / `save_session` / `load_session` / `cancel_parse`（仅本人任务）/ `list_plugins`（只读，保留可见性）/ `get_plugin_log`（只读）/ `list_user_presets` / `save_user_preset` / `delete_user_preset`（用户级数据）。
- sysadmin 专属：`install_plugin_zip` / `uninstall_plugin` / `set_plugin_enabled` / `reload_plugin` / `check_plugin_update` / `update_plugin`。
- 多用户语义要补的坑：`load_session` 的会话目录边界（会话是否跨用户可见）、`unload_file` 误卸他人文件、`cancel_parse` 影响他人导入——M1 可先"单人全共享"语义，文档明示；M3 再做归属隔离。

### 4.3 前端接入（复用现有架构，改动集中在 IPC 门面以下）
- `ui/src/ipc/` 新增第三实现 `http.ts`（与 `real.ts`/`mock.ts` 同级），`Ipc` 接口不变；`useMockIpc()` 环境开关扩为三分支。401/403 → 现有 `IpcError{code}`，**reportError/错误横幅/seq 失效链路零改动复用**。
- `state/session.ts` 增加 `role: 'viewer' | 'sysadmin'`；`SessionProvider` 启动时 `whoami`。
- 事件订阅：SSE 对应 `ab://` 四通道；401 过期 → 全局横幅"会话已过期" + 重新输入 token（Web 版需要一个 token 登录页；桌面版跳过）。

### 4.4 UI/UX 呈现原则
- **viewer 视角的 /plugins**：列表与日志保持可见（理解数据来源、排查自己文件为何解析失败），但安装/卸载/禁用/重载/更新按钮禁用 + 徽标「需要管理员」；或完全隐藏导航（产品决策，建议前者——与内建插件保护同款模式：可见但不可动）。
- 工作台内嵌管理入口（FilePanel 的卸载/更换插件）同样按角色禁用。
- 操作被拒时给出人话：`permission_denied` → "该操作需要管理员权限"，而不是笼统内部错误。
- **与 §2.1 联动**：在线版卸载影响所有用户，确认 Dialog + 审计日志（who/when/what，M3 可加 UI 查看页）应作为管理面操作的标准封装。
- sysadmin 与 viewer 同框时（未来），可加角色身份标识（顶栏徽标）避免"为什么我没有这个按钮"的困惑。

### 4.5 分期落地
1. **M1**：服务端角色 token + 管理面 403 + `whoami` + 前端按角色禁用控件 + `permission_denied` 文案。
2. **M2**：Web token 登录页、401 过期流、`http.ts` transport 全命令贯通。
3. **M3**：审计日志、会话/文件归属隔离、(可选) 服务端预设配额。
